# Walnut Pi CM2 Peripheral Assembly

## Cooling

The Walnut Pi CM2 is based on the Allwinner T527 octa-core high-performance processor. The module is compact in size, and its temperature can reach over 70°C when connected to an HDMI display, so additional cooling measures are recommended.

- Baseboard thermal pad only: 10-15°C lower;
- Heat sink only: 10-15°C lower;
- Baseboard thermal pad + heat sink: 20°C lower;
- Active cooler: 20°C+ lower (Recommended. As the temperature rises, the fan speed increases for better cooling performance)

## Baseboard Thermal Pad

A thermal pad is included with the IO baseboard purchase, which transfers heat to the baseboard.

![img](./img/cm2-peripherals/1.png)

Peel off the protective film from the thermal pad.

![img](./img/cm2-peripherals/2.png)

Attach it to the bottom of the CM2 module, then assemble the module onto the CM2 IO baseboard.

![img](./img/cm2-peripherals/3.png)

![img](./img/cm2-peripherals/4.png)

## Heat Sink (10-15°C Lower)

The heat sink comes with a tool kit.

![img](./img/cm2-peripherals/5.png)

The tool kit is Raspberry Pi compatible. Walnut Pi only requires 2 of the included thermal pads: the `thinnest square one` and the `smallest one`.

![img](./img/cm2-peripherals/6.png)

Apply the smallest square pad to the T527 main chip and the smallest pad to the power chip position. (These are the two areas with the highest heat generation.)

![img](./img/cm2-peripherals/7.png)

Screw the single-pass copper standoffs onto the heat sink.

![img](./img/cm2-peripherals/8.png)

### Non-fixed Baseboard Installation

The non-fixed baseboard installation is simple and easy to disassemble. Place the heat sink with the copper standoffs installed at the notch position as shown below, then tighten it with the small screws.

![img](./img/cm2-peripherals/9.png)

![img](./img/cm2-peripherals/10.png)

Then simply mount it onto the IO baseboard for convenient plug-in and removal.

### Fixed Baseboard Installation

The fixed baseboard method secures the CM2 module and the baseboard together, suitable for scenarios requiring long-distance transportation or where vibration is present during operation.

The included feet and long screws are required.

![img](./img/cm2-peripherals/11.png)

First, secure the 4 feet and long screws to the IO baseboard as shown below.

![img](./img/cm2-peripherals/12.png)

![img](./img/cm2-peripherals/13.png)

Install the CM2 module onto the baseboard.

![img](./img/cm2-peripherals/14.png)

Place the heat sink on top and tighten the screws.

![img](./img/cm2-peripherals/15.png)

## Active Cooler (Recommended, 20°C+ Lower)

The installation method for the active cooler is exactly the same as the heat sink above. After installation, simply plug the cooler connector into the IO baseboard. It starts when the CPU temperature exceeds 50°C, and the fan speed increases as the temperature continues to rise.

![img](./img/cm2-peripherals/16.png)

## RTC Battery

The CM2 IO baseboard features an RTC lithium battery holder, suitable for 3V 2032-size batteries. The charging function is configurable, making it suitable for rechargeable 3V lithium batteries.

![img](./img/cm2-peripherals/17.png)

## NVMe SSD

The CM2 IO baseboard supports 4 SSD sizes: 2230/2242/2260/2280. Simply install it using the standoff screws included with the baseboard. [NVMe SSD Usage Tutorial >>](../os_software/nvme.md)

## Case

Check the case accessory list, which includes the case, acrylic top cover, acrylic bottom cover, and standoff screws.

![img](./img/cm2-peripherals/20.png)

Install the 4 sets of standoffs at the 4 corners of the baseboard as shown below.

![img](./img/cm2-peripherals/21.png)

![img](./img/cm2-peripherals/22.png)

As shown below, insert the board into the case at an angle. Once the ports are aligned, apply a little force at the position indicated by the arrow to push it in. **If that does not work, install the board into the case first, then tighten the standoffs.**

![img](./img/cm2-peripherals/23.png)

After pushing it in, lay it flat as shown below:

![img](./img/cm2-peripherals/24.png)

Peel off the protective films from the 2 acrylic panels.

![img](./img/cm2-peripherals/25.png)

Screw the acrylic bottom cover into place. The bottom cover features wall-mounting holes.

![img](./img/cm2-peripherals/26.png)

Install the top cover in the same way, making sure the fan hole is positioned above the cooling fan.

![img](./img/cm2-peripherals/27.png)

Installation is now complete.
