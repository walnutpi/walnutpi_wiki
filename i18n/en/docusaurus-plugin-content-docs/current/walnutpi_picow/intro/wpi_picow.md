# WalnutPi PicoW

## WalnutPi PicoW

The WalnutPi PicoW is designed, developed, and manufactured in China. It is an MCU-level product within the WalnutPi ecosystem, based on the high-performance Espressif ESP32-S3 processor (with built-in WiFi and Bluetooth functionality). It features excellent RF performance, a compact and elegant appearance, and dimensions compatible with the Raspberry Pi PicoW. It is suitable for all kinds of electronic product DIY, commercial project development, and usage.
